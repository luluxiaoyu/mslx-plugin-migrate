# MSLX 整机文件迁移插件 (mslx-plugin-migrate)

用于 MSLX 面板的整机数据备份与迁移插件，支持服务端实例、FRP 穿透隧道、用户数据、全局设置及插件数据的导出与追加导入。

## 功能

- **服务端实例迁移**：支持全量或按需选择实例打包，自动处理跨系统平台（Windows / Linux 等）启动参数格式转换。
- **FRP 隧道恢复**：支持隧道配置与本地穿透配置备份，导入时自动解决 ID 冲突。
- **用户账号迁移**：采用纯追加模式导入，自动跳过同名用户，不影响已有用户数据。
- **全局与插件数据**：支持面板全局设置及第三方插件配置与程序的备份与还原（自动排除本迁移插件自身程序与归档历史）。
- **异步后台任务**：打包与解包全流程接入宿主任务中心，支持分阶段进度展示与任务取消。

## UI 在哪

- **主入口**：登录管理后台 -> 左侧菜单「系统设置」 -> 「守护进程设置」 -> 页面底部「整机文件迁移」卡片。
- **任务进度查看**：面板顶部导航栏「任务中心」。

## 使用方法

### 导出迁移包

1. 进入「系统设置」->「守护进程设置」，滑动至底部「整机文件迁移」卡片。
2. 点击右上角「导出迁移包」按钮。
3. 勾选需要导出的数据项（建议在导出前关闭正在运行的服务端以确保数据完整性）。
4. 点击「开始导出」，可在任务中心查看导出进度。
5. 导出完成后，在卡片中的「历史迁移包」列表点击「下载」保存 `.zip` 文件。

### 导入迁移包

1. 进入「整机文件迁移」卡片，点击「导入迁移包」按钮。
2. 选择导入方式：
   - **本地目录导入**：将迁移包直接放置于服务器指定目录（默认位于 `PluginsData/mslx-plugin-migrate/Imports`），点击「刷新列表」后选中对应文件。
   - **上传文件导入**：点击或将 `.zip` 格式的迁移包拖拽至上传区域。
3. 勾选需要导入的数据项。
4. 点击「开始导入」，任务将在后台自动执行追加恢复。
